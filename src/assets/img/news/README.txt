News images

Drop an image file here (.jpg, .jpeg, .png, .webp, or .gif) for a news post
that should show a picture, then reference it from src/_data/news.yaml with
the `image` field, e.g.:

  image: /assets/img/news/wearable-sensor.jpg

Keep filenames descriptive and web-sized (under ~1MB) since these are served
as-is, unoptimized.
