# The Stroud Lab — website

Source for **www.thestroudlab.com**.

The site is static HTML, generated by [Eleventy](https://www.11ty.dev/) from
Markdown, YAML, and a handful of templates. GitHub Actions rebuilds it and
publishes to GitHub Pages every time you push to `main`. There is no database,
no WordPress, and nothing to keep patched.

---

## The five-minute version

Almost everything you will ever want to change lives in **`src/_data/`**. Those
are plain text files. You can edit them in the GitHub web interface, click
*Commit changes*, and the site rebuilds itself in about a minute.

| To do this | Edit this file |
| --- | --- |
| Add a paper | `src/_data/publications.yaml` |
| Post a news item | `src/_data/news.yaml` |
| Add or remove a lab member | `src/_data/people.yaml` |
| Add software | `src/_data/software.yaml` |
| Add press coverage | `src/_data/press.yaml` |
| Change the menu | `src/_data/nav.json` |
| Change the address, email, links | `src/_data/site.json` |

Each of those files starts with a commented example. Copy it, fill it in, done.

### Adding a paper

Open `src/_data/publications.yaml`, and paste a block like this at the top:

```yaml
- year: 2026
  type: article
  authors: "Stroud, J.T., Someone, A.B."
  title: "The title of the paper"
  journal: "Nature"
  detail: "639: 589-601"
  doi: "https://doi.org/10.1038/..."
```

`type` is one of `article`, `inreview`, `popular`, `note`, or `volume`. Add
`featured: true` to also show it in the "Conceptual papers" list on the Research
page. Species names can be italicised with `<em>Anolis sagrei</em>`.

The page groups by year and builds the search box on its own.

### Adding a person

Open `src/_data/people.yaml` and copy a block. `group` must be one of `pi`,
`staff`, `postdoc`, `phd`, `incoming`, `undergrad`. If you have a photo, crop it
square, name it something like `firstname-lastname.jpg`, put it in
`src/assets/img/people/`, and set `photo: firstname-lastname.jpg`. Leave `photo`
out entirely and a neutral placeholder is used, so nobody has to wait for a
headshot to appear on the site.

### Changing wording on a page

The pages themselves are in `src/`: `index.njk` (home), `research.njk`,
`publications.njk`, `software.njk`, `people.njk`, `news.njk`, `outreach.njk`,
`join.njk`, `miami-lizards.njk`. They are HTML with a small amount of templating.
Editing the prose between the tags is safe.

### Changing the look

`src/assets/css/style.css`. The colours, fonts, and page widths are all defined
as variables in the first thirty lines, and everything else refers back to them.
The palette is taken from the lab logo.

## Setting up GitHub Pages (once)

1. Push this repository to `main`.
2. In the repository, go to **Settings → Pages**, and under *Build and
   deployment* set **Source** to **GitHub Actions**.
3. Still under Settings → Pages, set the **custom domain** to
   `www.thestroudlab.com` and tick *Enforce HTTPS* once the certificate is
   issued (this can take a few minutes to an hour).
4. At your domain registrar, create a `CNAME` record for `www` pointing to
   `jameststroud.github.io`. For the bare domain `thestroudlab.com`, add four
   `A` records pointing to `185.199.108.153`, `185.199.109.153`,
   `185.199.110.153`, and `185.199.111.153`, and GitHub will redirect it to
   `www`.
5. For `jamestsroud.com`, point it at the same place; GitHub only serves one
   custom domain per repository, so set up a redirect at the registrar instead.

The `src/CNAME` file in this repository keeps the custom domain from being reset
on each deploy. Do not delete it.

## Running it on your own machine (optional)

You do not need to do this to edit the site, but it is useful for bigger changes.

```bash
npm install
npm start          # then open http://localhost:8080
```

`npm run build` writes the finished site to `_site/`.

## How it is put together

```
src/
├── _data/            content: publications, people, news, software, press, nav
├── _includes/
│   └── base.njk      the page shell: masthead, nav, hero, footer
├── assets/
│   ├── css/style.css the whole design system
│   └── img/          heroes, portraits, photographs, logo
├── files/            PDFs (CV, handbook)
├── CNAME             the custom domain
└── *.njk             one file per page
.eleventy.js          build configuration and template filters
.github/workflows/    the deploy job
```
